# Свойства объектов на сцене

Для сериализации объектов на сцене используется формат свойств (см. Обобщённый формат хранения свойств).

Ниже приведён список свойств для разных типов объектов. Некоторые свойства являются опциональными
(могут отсутствовать), что явно указано для таких свойств. Свойства, имеющие значения по умолчанию,
могут отсутсвовать, несмотря на то что они не опциональны (в этом случае будут использованы
значения по умолчанию). Если свойства, не являющиеся опциональными и не имеющие значения по умолчанию,
отсутствуют, то это является ошибкой, и данные считаются некорректными.

## Node2D

* `parent: uint32` - _ОПЦИОНАЛЬНО_ - индекс родителя текущего узла в текущем поддереве. Если данный узел
не имеет родителя, то он считается корнем своего поддерева.
* `pos: vec2f` - позиция текущего узла относительно позиции родительского узла
(локальные координаты). Значение по умолчанию: `[0, 0]`.
* `scale: vec2f` - ратяжение текущего узла относительно родительского (локальное).
Значение по умолчанию: `[1, 1]`.
* `origin: vec2f` - точка, относительно которой происходит растяжение и поворот
(локальные координаты). Значение по умолчанию: `[0, 0]`.
* `rotation: float` - угол вращения узла по часовой стрелке относительно родительского
в радианах (локальное вращение). Значение по умолчанию: `0`.
* `setup: resource_index` - _ОПЦИОНАЛЬНО_ - идентификатор ресурса - функция инициализации сцены.
Идентификатор пакета обозначает идентификатор библиотеки, а идентификатор ресурса - идентификатор символа.
* `loop: resource_index` - _ОПЦИОНАЛЬНО_ - идентификатор функции обновления сцены, аналогичный `setup`.
* `link: resource_index` - _ОПЦИОНАЛЬНО_ - идентификатор участка сцены, на основе которого должен быть
создан текущий узел. Свойства текущего узла переопределят свойства корневого узла поддерева,
созданного из участка сцены. Идентификатор библиотеки может быть равен нулю - в этом случае
будет использован внутренний участок сцены из текущей сцены. Если тип узла, содержащего свойство `link`,
и узла, на который это свойство ссылается, не совпадают, то это является ошибкой.
* `name: string` - _ОПЦИОНАЛЬНО_ - имя текущего узла. Если задано, должно быть уникальным
в пределах сцены и участков сцены, включая внешние, иначе при загрузке возникнет ошибка. По этой
причине нужно с осторожностью использовать имена в участках сцены. Если данное свойство задано и является
пустой строкой, то это эквивалентно отсутствию свойства. Используя это свойство и тот факт, что заданные
в объекте свойства переопределяют свойства из участка сцены (см. свойство `link`), можно принудительно удалить
имя объекта, созданного с помощью участка сцены.

## SpriteNode

Имеет те же свойства, что и Node2D, а также:

* `size: vec2f` - размер текстуры, длина и ширина.
* `shader: resource_index` - идентификатор шейдера, который используется для отрисовки спрайта.
* `texture: resource_index` - идентификатор текстуры, которая используется для отрисовки спрайта.
* `layer: uint8` - слой, используемый для отрисовки спрайта. Значение по умолчанию: `0`.
* `visible: bool` - флаг видимости, от которого зависит, будет ли отрисован спрайт.
Значение по умолчанию: `true`.
* `texrect: float_rect` - прямоугольная область текстуры (размеры от 0 до 1), которая используется
для выбора участка текстуры, из которого будет создан спрайт. Значение по умолчанию: `[0, 0, 1, 1]`.
