# Системы отрисовки

Система отрисовки отвечает за алгоритм, с помощью которого отрисовываются объекты
на сцене. В частности, в её функции входят:
* отсечение невидимых объектов при отрисовке;
* выбор и упорядочение объектов для отрисовки кадра;
* обработка спецэффектов;
* вызов отрисовки с помощью низкоуровневого API.

Архитектура constructor2d разработана с учётом поддержки разных систем отрисовки,
предназначенных для отрисовки 2D-объектов.

Для возможности сохранения и чтения параметров системы отрисовки может требоваться
дополнительная служебная информация. Она хранится в файле сцены в виде пар "ключ-значение",
аналогично объектам на сцене (см. Поля данных объектов на сцене).

Далее приведены существующие системы отрисовки для архитектуры constructor2d.

## QTreeRenderSystem

### Описание алгоритма

Система отрисовки с помощью дерева квадрантов осуществляет выбор объектов на сцене
с помощью дерева квадрантов.

Вся сцена разделяется на квадранты одинакового размера. Группы по 4 смежных квадранта
принадлежат к квадрантам более верхнего уровня, которые, в свою очередь, имеют вдвое
большие размеры и тоже группируются по 4 и принадлежат к квадрантам более верхнего уровня.
Таким образом, образуется древовидная структура, на самом верхнем уровне которой
(в корне дерева) находится один большой квадрант, охватывающий всю сцену.

Все графические объекты принадлежат к наименьшему возможному квадранту, т.е. наиболее
глубокому квадранту в дереве. Если объект выходит за границы квадранта из-за своего
размера или местоположения, то он привязывается к квадранту верхнего уровня, (вплоть до
корневого квадранта) вмещающему этот объект целиком. При обновлении геометрических
свойств объекта выполняется проверка и, если нужно, происходит перемещение объекта в
подходящий квадрант.

2D-камера определяет прямоугольную область, которая будет отображена на экран во
время отрисовки кадра. При отрисовке в дереве квадрантов выполняется поиск, в котором
для отображения на экране выбираются только те объекты, которые пересекаются с областью
камеры. При этом, проверка объектов выполняется только в тех квадрантах, которые
пересекаются с областью камеры. Поиск таких квадрантов получается довольно быстрым за
счёт их упорядочения в виде дерева, потому что при спуске от корня до меньших квадрантов
могут быть отсечены квадранты, заведомо не пересекающиеся с областью камеры.

### Данные для сериализации

* `quad_start: float[2]` - координаты левого верхнего угла левого верхнего квадранта на сцене.
* `quad_size: float[2]` - размеры наименьшего квадранта, т.е. квадранта, находящегося на самом
нижнем уровне дерева.
* `size: uint32[2]` - размеры сцены, выраженные в количестве наименьших квадрантов.
